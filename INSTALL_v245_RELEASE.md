# Avicularia v245 — основна версія (Worker v110)

Адреса: https://anthonybatyk.github.io/avicularia-released-program/
Cloudflare Worker: `avicularia-api` (`https://avicularia-api.anthonybatyk.workers.dev`)

## Безпечне встановлення

1. Зробіть окремі резервні копії **основної D1** через Cloudflare, експортуйте КБЖВ JSON і ZIP тренувань із поточного основного сайту. Додатково збережіть старий ZIP файлів GitHub та код поточного основного Worker.
2. З'ясуйте фактичну версію Worker `avicularia-api` у Cloudflare або через `/health`. Сайту v245 потрібен Worker v110 із підтримкою `/sync/v2/*` та `/avicularia/archive/v2/*`. Якщо основний Worker старіший, оновіть **лише `avicularia-api`**, використовуючи наданий окремий код v110 і зберігши ВСІ змінні, секрети та правильну прив'язку `DB` до **основної** D1. Параметр `ALLOWED_ORIGIN` має бути `https://anthonybatyk.github.io`. Жодну D1 не обнуляйте та не переприв'язуйте до тестової.
3. Після перевірки Worker розпакуйте та завантажте **вміст** цієї папки у корінь репозиторію `avicularia-released-program` на GitHub. Файли ZIP не потрібно класти в GitHub одним ZIP-файлом.
4. Перевірте `release.json`, PWA, версії v245/v110 у Консолі, входи, КБЖВ, фото, архів і тренування, звірте числа до/після, виконайте читання/перевірку синхронізації. Лише тоді виконуйте тестове збереження одного нового запису, не підтверджуйте заміну даних при конфлікті.
5. Після перевірки НЕ очищайте Safari/IndexedDB або D1. В окремому тестовому сайті та Worker залишаються старі адреси й дані; вони не переносяться до основної D1 автоматично.

## Уточнення щодо даних

- Заміна файлів GitHub не переносить акаунти й записи між тестовою та основною D1. За потреби користуйтеся штатним експортом/імпортом **лише після створення резервної копії**.
- В основній версії замінено namespace браузерних даних на `avicularia_*` та окремий production IndexedDB. Тестові `avicularia_testing_*` залишаються незміненими. На тому самому браузері можливе повторне входження в основний акаунт.
- Поштучна синхронізація не вмикається автоматично від одного розгортання. Для існуючого акаунта спочатку підтвердіть правильність сервера й локальних даних.
- Без доступу до чинної основної D1 й конфігурації Workers неможливо гарантувати безпечний результат *живого* оновлення лише статичними тестами файлів.

## Швидка перевірка v245

«Зручності» → «Вуглеводи без цукрів»: у порожніх полях «Вуглеводи, г» та «Цукри, г» видно `###` замість чисел. Після введення власних значень формула та кнопки працюють як раніше. Перед публікацією переконайтеся, що адреса API відповідає саме цьому середовищу. Не очищайте IndexedDB, Safari або D1. Worker v110 не змінювати.

## Правка v245
Швидкі ваги спрацьовують з першого дотику при фокусі поля на iOS. Розбір «Білки: 12,5» та інших семи показників у формі назва: значення. Сама кнопка «До калькулятора» лише додає текст до поля; для внесення у підсумок натисніть «Додати» в Калькуляторі. Worker v110 лишається без змін. Перед випуском на основний сайт зробіть резервний JSON КБЖВ; кеш не очищуйте.
